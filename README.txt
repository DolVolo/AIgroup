แขนกล 4 แกน ควบคุมด้วยมือถือ Android ผ่านบลูทูธ (BLE)
Robot Arm 4DOF — Arduino Nano + BLE module + MIT App Inventor
=====================================================================

ไฟล์ในโปรเจกต์
---------------------------------------------------------------------
RobotArm_BT4/RobotArm_BT4.ino   โค้ด Arduino (อัปโหลดลงบอร์ด Nano)
RobotArmBLE.aia                 โปรเจกต์แอป Android สำหรับ Import เข้า MIT App Inventor
aia_ble_src/                    ไฟล์ข้างใน RobotArmBLE.aia ที่แตกออกมาให้อ่านได้ (ไม่ต้องใช้ตอนสร้างแอป)
MIT_App_Inventor_Blocks_Blueprint.txt   แผนบล็อกแบบเก่า (สำหรับ HC-06) เก็บไว้อ้างอิง
คู่มือ_MIT_App_Inventor_แขนกล.pdf       คู่มือเดิมจากแพ็กเกจ (เขียนสำหรับ HC-06)


อุปกรณ์ที่ต้องใช้
---------------------------------------------------------------------
- Arduino Nano (รุ่นที่ใช้ชิป USB CH340 ก็ได้)
- โมดูลบลูทูธ BLE แบบ HM-10 / AT-09 / BT05 (Bluetooth 4.0)
- เซอร์โว 4 ตัว (เช่น SG90 หรือ MG90S)
- แหล่งจ่ายไฟ 5V สำหรับเซอร์โว อย่างน้อย 2A
- สาย USB แบบรับส่งข้อมูลได้ (ไม่ใช่สายชาร์จอย่างเดียว)
- มือถือ Android ที่มีบลูทูธ 4.0 ขึ้นไป
- คอมพิวเตอร์ Windows สำหรับอัปโหลดโค้ด


=====================================================================
ขั้นที่ 1: ต่อสาย
=====================================================================

โมดูลบลูทูธ -> Arduino Nano
  VCC  -> 5V
  GND  -> GND
  TXD  -> D10
  RXD  -> D11

เซอร์โว (สายส้ม/เหลือง = สัญญาณ) -> Arduino Nano
  เซอร์โว 1  ฐานหมุน  -> D3
  เซอร์โว 2  ไหล่      -> D5
  เซอร์โว 3  ข้อศอก    -> D6
  เซอร์โว 4  มือจับ    -> D9

ไฟเลี้ยงเซอร์โว
  สายแดงของเซอร์โวทุกตัว -> +5V ของแหล่งจ่ายไฟแยก
  สายน้ำตาล/ดำทุกตัว      -> GND ของแหล่งจ่ายไฟแยก
  ** ต้องต่อ GND ของแหล่งจ่ายไฟแยกเข้ากับ GND ของ Nano ด้วย **
  (ถ้าดึงไฟเซอร์โวจาก Nano อย่างเดียว บอร์ดอาจรีเซ็ตเองตอนเซอร์โวขยับ)

ห้ามต่อโมดูลบลูทูธที่ขา D0/D1 (TX/RX) เพราะจะทำให้อัปโหลดโค้ดไม่ได้


=====================================================================
ขั้นที่ 2: อัปโหลดโค้ดลง Arduino Nano
=====================================================================

1. ดาวน์โหลดและติดตั้ง Arduino IDE จาก https://www.arduino.cc/en/software
2. เปิดไฟล์ RobotArm_BT4/RobotArm_BT4.ino
   (ไม่ต้องลงไลบรารีเพิ่ม เพราะ Servo และ SoftwareSerial มีมาให้แล้ว)
3. เสียบสาย USB จาก Nano เข้าคอม
4. ตั้งค่าในเมนู Tools
     Board     : Arduino Nano
     Processor : ATmega328P 
     Port      : พอร์ตที่ชื่อ USB-SERIAL CH340 (เช่น COM7)
                 อย่าเลือกพอร์ตที่เป็น "Standard Serial over Bluetooth link"
5. กดปุ่ม Upload (ลูกศร ->)
6. รอจนด้านล่างขึ้นข้อความ "Done uploading."

ถ้าอัปโหลดไม่ผ่าน (ขึ้น stk500_getsync() not in sync / programmer is not responding)
  - เปลี่ยน Processor เป็น ATmega328P (ตัวที่ไม่มีคำว่า Old Bootloader) แล้วลองใหม่
  - ถอดสายโมดูลบลูทูธออกชั่วคราวระหว่างอัปโหลด
  - ปิด Serial Monitor และโปรแกรมอื่นที่ใช้พอร์ตนี้อยู่
  - กด Upload แล้วพอขึ้นคำว่า "Uploading..." ให้กดปุ่ม RESET บน Nano 1 ครั้ง
  - เปลี่ยนสาย USB หรือช่อง USB
  - ถ้าคอมมองไม่เห็นพอร์ต ให้ติดตั้งไดรเวอร์ CH340

ข้อความ "Sketch uses ... bytes" เป็นแค่การบอกขนาดโปรแกรม ไม่ใช่ข้อผิดพลาด


=====================================================================
ขั้นที่ 3: สร้างแอป Android ด้วย MIT App Inventor
=====================================================================

1. เข้า https://ai2.appinventor.mit.edu แล้วล็อกอินด้วยบัญชี Google
2. เมนู Projects -> Import project (.aia) from my computer
3. เลือกไฟล์ RobotArmBLE.aia
   (ถ้าชื่อซ้ำกับโปรเจกต์ที่มีอยู่ ให้ตั้งชื่อใหม่ เช่น RobotArmBLE_v2)
4. แอปมี BluetoothLE extension ของ MIT รวมอยู่แล้ว ไม่ต้องติดตั้งเพิ่ม
   ถ้า Import แล้วไม่มี extension ให้ดาวน์โหลด edu.mit.appinventor.ble-20240822.aix
   จาก https://mit-cml.github.io/extensions/ แล้วเพิ่มเองที่ Palette -> Extension -> Import extension
5. เมนู Build -> Android App (.apk)
6. สแกน QR Code ด้วยมือถือ หรือดาวน์โหลดไฟล์ .apk ไปติดตั้งในมือถือ
   (มือถืออาจถามให้อนุญาต "ติดตั้งแอปจากแหล่งที่ไม่รู้จัก" ให้กดอนุญาต)

แนะนำให้ใช้ไฟล์ .apk แทนแอป MIT AI2 Companion
เพราะบน Android 12 ขึ้นไป Companion มักใช้บลูทูธไม่ได้

ค่าสำคัญที่ตั้งไว้ในแอป (ถ้าสร้างแอปเอง ต้องตั้งให้เหมือนกัน)
  - BluetoothLE1 -> NullTerminateStrings = ไม่ติ๊ก (False)
    ถ้าติ๊กไว้ แอปจะส่งตัวอักษรขยะต่อท้ายคำสั่ง และ Arduino จะอ่านคำสั่งไม่ออก
  - ส่งข้อมูลไปที่ Service UUID        0000FFE0-0000-1000-8000-00805F9B34FB
                 Characteristic UUID 0000FFE1-0000-1000-8000-00805F9B34FB


=====================================================================
ขั้นที่ 4: เชื่อมต่อและใช้งาน
=====================================================================

1. เสียบไฟ Nano ไฟ LED ของโมดูลบลูทูธจะกะพริบ (รอการเชื่อมต่อ)
2. มือถือ: เปิดบลูทูธ และเปิดตำแหน่ง (GPS)
3. ไม่ต้องจับคู่ (Pair) โมดูลในหน้าตั้งค่าบลูทูธ
   ถ้าเคยจับคู่ไว้ ให้กด "ลืมอุปกรณ์" ออกก่อน
4. เปิดแอป -> กด "1. ค้นหา" -> ถ้ามีหน้าต่างขอสิทธิ์ ให้กด "อนุญาต"
5. รอ 3-5 วินาที -> กด "2. เลือกอุปกรณ์" -> เลือกชื่อโมดูล
   (เช่น HMSoft, BT05, AT-09 หรือ MLT-BT05)
6. เชื่อมต่อสำเร็จเมื่อ
     - แอปขึ้น "สถานะ: เชื่อมต่อแล้ว" เป็นสีเขียว
     - ไฟ LED ของโมดูลเปลี่ยนจากกะพริบเป็นติดค้าง
7. เลื่อนแถบเพื่อขยับแต่ละข้อต่อ
     ฐานหมุน / ไหล่ / ข้อศอก / มือจับ  (0-180 องศา)
   ปุ่ม "เปิดมือจับ" = 150 องศา, "หุบมือจับ" = 60 องศา
   ปุ่ม "กลับท่าเริ่มต้น" = ทุกตัวกลับไปที่ 90 องศา


=====================================================================
รูปแบบคำสั่งที่แอปส่งไปที่ Arduino
=====================================================================

  S<เลขเซอร์โว>:<องศา>   แล้วปิดท้ายด้วยขึ้นบรรทัดใหม่ (\n)

  ตัวอย่าง  S1:120   = ฐานหมุนไปที่ 120 องศา
            S4:60    = มือจับไปที่ 60 องศา

ถ้าจะทำแอปหรือโปรแกรมอื่นมาควบคุม ส่งข้อความรูปแบบนี้ได้เลย


=====================================================================
แก้ปัญหาที่พบบ่อย
=====================================================================

ปัญหา: หาโมดูลไม่เจอในหน้าตั้งค่าบลูทูธของมือถือ
  -> เป็นเรื่องปกติของโมดูล BLE ไม่ต้องหาในหน้าตั้งค่า ให้ค้นหาจากในแอปแทน

ปัญหา: กด "2. เลือกอุปกรณ์" แล้วรายการว่าง
  -> เปิด GPS, อนุญาตสิทธิ์ "อุปกรณ์ใกล้เคียง" ให้แอป
     (ตั้งค่า -> แอป -> RobotArmBLE -> สิทธิ์) แล้วกด "1. ค้นหา" ใหม่

ปัญหา: แอปขึ้น "ไม่ตอบสนอง" ตอนเชื่อมต่อ
  -> กด "รอ" แอปกำลังรอการเชื่อมต่ออยู่

ปัญหา: ไฟ LED ของโมดูลติดค้างก่อนเปิดแอป
  -> มีอุปกรณ์อื่นเชื่อมต่อโมดูลอยู่ ปิดบลูทูธของเครื่องอื่น
     หรือถอดไฟ Nano 5 วินาทีแล้วเสียบใหม่

ปัญหา: เชื่อมต่อได้ แต่เลื่อนแถบแล้วเซอร์โวไม่ขยับ
  -> เช็กสาย TXD -> D10 และ RXD -> D11 (ห้ามสลับ)
  -> เช็กว่าต่อ GND ของไฟเซอร์โวเข้ากับ GND ของ Nano แล้ว
  -> ใช้แอป nRF Connect ตรวจว่าโมดูลมี Service FFE0 และ Characteristic FFE1

ปัญหา: วิธีเช็กว่าโมดูลเป็น BLE หรือ Classic
  -> ติดตั้งแอป "Serial Bluetooth Terminal" -> เมนู Devices
     ถ้าเจอในแท็บ "Bluetooth LE" = โมดูล BLE (ใช้แอป RobotArmBLE นี้)
     ถ้าเจอในแท็บ "Bluetooth Classic" = HC-05/HC-06 (ต้องใช้แอปแบบ BluetoothClient)
